# Introducción a los Métodos Numéricos

Los métodos numéricos son técnicas mediante las cuales es posible formular problemas matemáticos de tal forma que puedan resolverse usando operaciones aritméticas. Son esenciales cuando:

1. No existe solución analítica conocida
2. La solución analítica es demasiado compleja
3. Se requiere una solución aproximada con cierta precisión controlada

En este tema exploraremos los conceptos fundamentales como:
- Tipos de errores (truncamiento, redondeo)
- Precisión vs exactitud
- Estabilidad numérica
- Convergencia de métodos iterativos

Los métodos numéricos son la base para resolver problemas científicos y de ingeniería en computadoras.
